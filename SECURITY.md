# Security Policy

## Supported Versions

| Version | Security Support |
| --- | --- |
| `0.x` | Best-effort security fixes during public preview |

## Reporting A Vulnerability

Please report security issues privately by email:

```text
fahim.tayebee@gmail.com
```

Please do not publicly disclose vulnerabilities before a fix is available.

Preflight is maintained on a best-effort basis during public preview. Response times may vary, but reports with clear reproduction steps and affected versions are appreciated.

Preflight is a static audit helper. It can help identify common project risks, but it does not guarantee complete application security and does not replace a professional security review.
